
# AoPS Intermediate Counting & Probability: A Computational Journey

This repository contains C++ implementations and general solvers for problems found in the Art of Problem Solving (AoPS) Intermediate Counting & Probability textbook.

## 🛠 Project Philosophy
- **Verify by Hand, Validate by Code:** Solve the mathematical proof first, then write a general script to confirm results for larger test cases.
- **Avoid Brute Force:** Where possible, implement the underlying combinatorial formula (Inclusion-Exclusion, Generating Functions) rather than nested loops.
- **Handle Large Numbers:** Use `long long` or custom BigInt logic to handle the massive counts typical of intermediate combinatorics.
